Comment j'interviens

Construire, transformer, optimiser ou piloter.

Construire

Assistant IA, agent, automatisation, application métier, API, pipeline Data ou reporting.

Transformer

Moderniser une application, remplacer un outil fragile, reprendre un prototype ou faire évoluer l’architecture.
